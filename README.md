# Task Management System – Backend API

This project is a backend-only REST API for a Task Management System.
It is designed to demonstrate backend development skills including
authentication, authorization, database design, filtering, and analytics.

Frontend is intentionally excluded to focus on backend architecture,
security, and scalability. All APIs are testable using Postman and
documented using Swagger (OpenAPI).

---

## Features

- User Registration & Login (JWT Authentication)
- Protected Routes
- Task CRUD Operations
- Task Filtering (status, priority, category, search)
- Overdue Task Detection
- Task Statistics Dashboard API
- Secure User-based Access Control
- Swagger API Documentation

---

## Tech Stack

- Node.js
- Express.js
- MongoDB & Mongoose
- JWT Authentication
- Swagger (OpenAPI)
- Postman (API Testing)
